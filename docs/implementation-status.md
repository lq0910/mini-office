| 能力 | 状态 | 说明 |
|---|---|---|
| 预设样式 | ✅ | 16 个：正文、标题 1–4、标题、副标题、引用、题注、正文首行缩进、无间隔、强调引用、列表段落、列表项目符号、列表编号、等宽文本 |
| 实时预览 | ✅ | 卡片用样式自身字体/字号/粗细/颜色/对齐渲染样式名，所见即所得 |
| 批量套用 | ✅ | 拖选多段一次套用，只产生一条撤销记录；套用后恢复选区，可连续比较 |
| 当前样式识别 | ✅ | 先看 `w:pStyle`，再按排版特征反推；工具栏按钮显示「标题 1」等名称 |
| 清除格式 | ✅ | 回到文档默认字体与无缩进状态，并解除样式关联 |
| 新建样式 | ✅ | 以当前段落格式为蓝本命名保存，进入「本文档样式」 |
| 样式集 | ✅ | 「保存此文档为我的样式集」写入本机；任意文档可一键导入，ID 冲突自动改名 |
| 导入文档样式 | ✅ | 解析 `styles.xml` 中实际用到的段落样式，随文档进入样式库 |
| 写回 DOCX | ✅ | 保存时把用到的样式按 CT_Style 顺序追加进 `styles.xml`；内置样式用英文名，Word 侧仍是「标题 1」 |
| 快捷键 | ✅ | ⌘/Ctrl+⌥+1~4 套用标题 1–4，⌘/Ctrl+⇧+N 回到正文（与 Word 一致） |

设计取舍：

- 样式是「完整替换」而不是叠加：段落级对齐/缩进/间距/行距/边框全部由样式决定，字体整体重写，只保留用户的下划线、删除线、突出显示与上下标。
- 列表样式只写段落标记文本，不生成 `numbering.xml`；避免与 Word 内置列表样式叠加成双重编号。
- 未在样式中声明字体的样式（正文、标题）应用时回落到文档默认字体，换默认字体后正文会跟着变。
- 校验：`tests/word-styles.test.ts` 21 项（含 DOCX 往返与 `styles.xml` 元素顺序），`scripts/verify-word-styles.mjs` 端到端。
