# Mini Office 0.1.10

<!-- 功能：汇总相对 0.1.9 的功能迁移、兼容修复、性能与桌面体验改进；时间：2026-11-14；作者：lq。 -->

0.1.10 将 0.1.9 中的定制 Word 新核心从开发入口升级为默认编辑核心，完成工具栏、工作区、桌面文件操作、邮件合并和打印/PDF 的整体接入，并集中改进长文档显示、跨页表格、页眉页脚、旧版 DOC 与目录导航。

以下按功能汇总 **0.1.9 → 0.1.10** 的累计改动。

## Word 新核心默认启用

- **统一编辑与保存**：新建、打开、恢复、编辑、保存、另存为、打印和导出使用同一套新核心会话；发布构建默认启用，不再依赖开发开关，也不会在保存失败时静默切回旧保存器。
- **现有界面完整接入**：保留 Mini Office 的六标签工具栏、主题和控件，字体、段落、页面、表格、图片、样式、查找、邮件合并及输出入口均接入新核心。
- **共享撤销与重做**：正文、页眉页脚、文本框、样式和页面设置共享历史；连续输入分组，独立工具操作可单步撤销，切换标签或保存后保留编辑历史。

## 文字、段落与样式

- **字体与字符格式**：支持系统字体、中西文字体、中文字号、自定义字号、加粗、斜体、下划线、删除线、文字颜色及高亮；混合字体、字号和行距正确显示，避免把默认值当成选区格式。
- **段落设置**：对齐、首行/悬挂/左右缩进、段前段后、固定/最小/倍数行距及分页属性接入新核心；段落对话框仅提交实际修改的字段，避免覆盖混合选区的其他格式。
- **列表与编号**：正文及支持的表格、页眉页脚、文本框区域可使用项目符号、多级编号、续项、空项退出和层级调整，新增编号定义随文档保存。
- **样式管理**：支持应用、新建、改名、删除样式，以及样式集保存、导入和删除；导入时处理样式 ID 冲突，保留其他部件仍依赖的格式继承。
- **格式刷**：支持单次、连续格式刷与 Esc 退出，可在正文、表格及可编辑区域之间应用字符和段落格式。
- **查找替换**：支持当前编辑区跨格式查找、高亮、前后导航、大小写匹配及全部替换；批量替换合并为一步撤销。
- **复制粘贴**：支持来源格式、目标格式、纯文本三种粘贴模式原位切换，切换不重复插入；图片粘贴接入新核心。

## 页面、目录与页眉页脚

- **页面设置**：分节纸张、横纵向、四侧页边距、分页符和编辑标记接入新核心；页边距拖动时预览，松手提交，取消不修改文档。
- **标尺与制表位**：支持正文及适用编辑区域的缩进拖动、制表位增删和缩放换算；复杂坐标场景限制不适用的操作。
- **目录插入与更新**：按标题 1–3 级生成目录，页码跟随真实分页和分节编号；复杂、损坏或夹带正文的目录拒绝覆盖并提示。
- **目录单击导航**：普通单击即可跳到对应标题或书签，继续兼容 Ctrl/Command 单击；拖选目录文字时不误触跳转，导航不产生未保存修改。
- **旧目录恢复兼容**：识别旧版 DOC 转换恢复内容中的连续目录结构，修复显示和导航；保留原 XML、显式格式及文件字节，不把普通书签链接误当目录。
- **页眉页脚编辑**：支持双击进入、富文本、布局表格、图片、列表和域，以及首页不同、奇偶页不同、链接前节、页码起始值及距边设置；编辑区尚未退出时也可保存。
- **浮动页码文本框**：正确定位并编辑页脚中的已有页码框，保留原字体、字号、位置、PAGE 域、邻接形状与后备分支，避免重复生成普通页脚页码。
- **缩放与状态栏**：支持 Ctrl+滚轮在 40%–250% 范围缩放正文，保持鼠标附近的内容位置，状态栏同步更新；普通滚轮继续滚动，当前页、总页数、字数和字符数接入新核心。

## 表格、图片与版式修复

- **表格操作迁移**：支持插入、整表移动、行列与矩形选区、增删行列、合并拆分、平均分布、适应页宽、重复表头，以及宽高、对齐、底纹、垂直对齐、边框和尺寸拖动。
- **表格保存保真**：保留未修改的表格、行、单元格 XML、段落来源和纵向合并续格，减少局部编辑对原结构的影响。
- **长表格分页**：修复切点落在表格末尾边框或留白区时整轮分页失败、状态栏退回一页和正文连续显示的问题，兼容 WebKit 的边框与字形取整差异。
- **跨页表格显示**：修复纵向合并格边框穿过页缝、长文字被遮挡、重复表头列错位，以及页缝额外撑出表格列的问题；跨页文字按完整行安放。
- **页脚与正文空间**：修正浮动页码框高度误测、页脚预留重复扣减及页底定位，避免正文可用高度错误和跨页内容侵入物理纸边。
- **独立纸面与页边**：统一正文和分页快照的纸边与页缝绘制，修复页底单击、跨页选择时两页看似连成一张的问题。
- **图片与文本框**：支持图片插入、粘贴、选择、删除、尺寸调整和常用环绕；已有文本框可编辑文字、列表、样式及内联图片，保存时保留媒体关系和来源绘图属性。

## 长文档加载与滚动

- **渐进装载**：正文分批进入编辑器，保留完整文档模型；移除“正在加载后续页面…”提示，后台装载继续进行。
- **分页显示优化**：十页及以上文档采用活动编辑页与可视页快照显示，按视窗缓存页面；跨页选区、真实拖选、输入法组合和页眉页脚编辑保留完整编辑层。
- **减少滚动重排**：当前页统计和滚动使用缓存的页界与几何数据，布局、缩放或窗口尺寸变化后再更新，减少滚动时反复测量整篇正文。
- **减少重复工作**：加入增量续排、等高段落快速分页、分节宽度缓存和 DOM 批量提交；文字压缩测量按帧分批，统计与样式预览复用缓存，减少无关事务刷新工具栏。
- **避免重复挂载**：修复异步邮件配置读取完成后整篇编辑器重新挂载，以及大量页脚/边距控件逐个插入带来的额外开销。
- 屏幕快照仅用于显示，保存、打印和 PDF 仍从完整文档生成；首次完整排版、长表格和全局格式修改仍需持续优化。

## 邮件合并、打印与 PDF

- **邮件合并整体迁移**：Excel/CSV 导入、字段插入、逐条预览、多条件筛选、排序、记录勾选、空值与文件命名选项均接入新核心，配置随模板保存并可重开。
- **批量文档输出**：支持合并为可编辑 Word、单份 DOCX、逐记录 DOCX ZIP、PDF 和逐记录 PDF ZIP；处理常用合并域、嵌套 IF、NEXT/NEXTIF/SKIPIF，以及按记录重映射书签、编号等引用。
- **保护源模板**：预览不改模板正文或历史；输出失败、取消时不修改源模板，成品清理邮件连接。
- **打印预览**：复用真实分页，支持翻页、缩放、方向设置与预览页边距拖动，兼容混合纸张和重复表头。
- **打印版式修复**：修复整页输出安全余量裁掉页脚、混合横纵向纸张触发整体缩小等问题；取消或关闭预览时不提交未完成的页边距拖动。
- **PDF 导出**：支持页码范围、进度、取消和保存；输出固定在捕获的文档版本，取消时丢弃未完成结果并释放临时会话，清理不参与输出的光标占位元素。

## 桌面与文件安全

- **保存状态一致性**：保存按捕获版本生成字节，写盘成功后再确认；失败或取消不清除修改标记，保存期间新增的输入继续保持未保存状态。
- **另存与恢复**：另存后切换到新路径，避免后续保存写回旧文件；自动快照保存 DOCX 字节，恢复重新打开完整核心，未保存快照要求另存副本。
- **多标签与退出**：非活动标签可独立保存，关闭前等待已发起的快照并重新检查修改状态；关闭后释放会话、共享解析 worker 和内嵌字体，迟到回调不再访问已销毁编辑器。
- **统一文件入口**：冷启动、系统打开、桌面/网页拖入及手动打开走同一新核心处理器；无宏 DOCX 模板支持 `.dotx` 扩展保存。
- **DOC 格式识别**：真正的二进制 DOC 先转为 DOCX；内容已是 DOCX、仅扩展名为 `.doc` 的文件直接使用原字节，不重复转换或误报转换损失，非 Word ZIP 不按文件名冒充 Word。
- **系统字体度量**：桌面读取实际字体、中英文别名及 TTC/OTC 字面度量并供分页使用，改进本机字体与缺失字体识别。
- **macOS 图片剪贴板**：支持 PNG 与携带尺寸、环绕信息的 HTML 原生剪贴板，剪切仅在剪贴板写入成功后删除原内容。
- **兼容性保护**：按新核心实际部件生成兼容报告，保留宏、签名、强保护的只读限制及复杂结构另存策略，能力限制在工具栏、事务和保存层保持一致。
- **菜单与模板**：菜单和命令面板接通新核心的打印、PDF、查找、样式、标尺入口；房屋租赁合同模板直接从内置 DOCX 创建未保存副本，不绑定或覆盖模板原件。
- **小窗口菜单**：上下文菜单限制在窗口边缘内，窄窗口或矮窗口可滚动访问全部命令。

## 已知限制

- 长文档首次完整排版仍有成本，真实业务文件的持续滚动、编辑延迟和内存表现仍需验收；不承诺任意大文件全程流畅。
- 旧版 DOC 转换、字体替代和跨引擎度量仍可能导致与 Microsoft Word 的分页或版式差异；二进制 DOC 不提供原格式往返保存。
- 复杂目录更新、多栏/竖排标尺及部分嵌套、锁定区域受能力保护；修订审阅、批注及高级绘图等尚未提供完整专用编辑流程。
- macOS Developer ID 签名与 Apple 公证、Windows/Linux 实机安装、其他平台原生位图剪贴板、实际打印机出纸及完整跨平台性能验收仍待完成。
