# Mini Office 0.1.8

<!-- 功能：记录 Word/DOC 保真改进及当前验证边界；时间：2026-11-05；作者：lq。 -->

0.1.8 延续 0.1.7，集中改进 Word 编辑器与旧版 DOC 转换中的文字、分页和表格属性处理。本版本也增加了可配置的页面裁剪标记，帮助编辑时识别版心范围。

## 改进

- **Word 页面辅助**：按分节页边距显示四角裁剪标记，可在视图设置中关闭；标记不参与文档编辑、打印和 PDF 导出。
- **段落排版**：区分段落标记与正文字符格式，保留孤行控制、页面网格、上下文段距等语义，并改进标题与后续段落的分页预检。
- **旧版 DOC 导入**：保留表格首选宽度、自适应布局、单元格边距与垂直对齐；改善备用字体、文本框定位、页码域和表格尺寸单位处理。
- **回归覆盖**：新增 DOC/DOCX 结构、字体度量、分页、制表位与表格属性测试。

## 验证

- `pnpm verify`：TypeScript 检查、Vitest 与 Web 生产构建通过。
- Vitest：62 个测试文件，614 项通过、3 项私人样本测试跳过。
- 未在本轮重新打包 Tauri 桌面应用，也未执行 WebView 实机验收。
- 公开语料仍有像素差异。采购 DOC 样本仍比其 Word 基准少一页；本版本不宣称 Word 版面保真验收完成。

## 已知限制

- 字体替代仍会影响部分字形与间距，旧版 DOC 的复杂表格、编号和分页需继续验证。
- 采购样本的页数差异及标题位置偏差尚未解决；不能通过强制补页或固定偏移掩盖。
- 浏览器生产构建不替代 macOS、Windows WebView 与 Office 实际文件往返验收。
