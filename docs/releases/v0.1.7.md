# Mini Office 0.1.7

<!-- 功能：汇总 0.1.6 之后 Windows 顶栏合并、工作表填充柄与打印增强、文件关联扩展与一批网格修复；时间：2026-11-01；作者：lq。 -->

0.1.7 包含 0.1.6 之后的全部改动：Windows 端把文档标签并入顶栏一行，工作表补上填充柄拖动、公式引用高亮与打印标题／打印缩放，打印预览支持在页面上直接拖动页边距，PDF / Markdown / HTML 登记到系统「打开方式」，并修掉冻结区表头错位、边框叠画与缩放坐标偏移。

## 新增功能

### Windows 顶栏合并

- **标签并入标题栏**：Windows 桌面端去掉系统标题栏，文档标签直接排进顶栏同一行，省掉一条纵向占位；macOS 保持 Overlay 红绿灯不变，两种形态共用同一套标签逻辑。
- **自绘窗口按钮**：最小化、最大化 / 向下还原、关闭由应用绘制，只在去掉系统标题栏的 Windows 端出现；点击按钮、标签、输入框、链接时不会误触发窗口拖动。
- **标签条统一**：标签列表抽成 `TabStrip`，合并态与独立标签栏共用拖拽排序与关闭逻辑；合并态标签压缩到 26px 高度，与 40px 顶栏对齐。

### 工作表填充柄

- **等差数列延展**：单列或单行纯数字拖动填充时按等差数列推算；文本与混合内容按周期重复，与 Excel 的填充柄一致。
- **坐标换算统一**：屏幕坐标换算回行列号时兼容 CSS 缩放、滚动位置与冻结窗格，填充柄与拖选共用同一套换算。
- **边缘自动滚动**：拖到网格边缘自动滚动，长距离填充不必先滚动再拖。
- **单条撤销**：拖动期间只画预览框，松手才写入数据，整次填充合并为一条撤销记录。

### 工作表打印

- **打印标题（顶端标题行）**：新增「打印标题」输入，支持 `1:2`、`$1:$2`、`2` 等写法，自动裁剪到打印范围；每页重复输出，支持多行标题；正文分页跳过标题行，不会同一行打印两次。
- **向后兼容**：未配置标题行时沿用「首行当表头」的历史行为，已有文档的打印结果不变。
- **打印缩放五种语义**：统一到一个下拉表达——无缩放 / 工作表一页 / 所有列一页 / 所有行一页 / 自定义比例，与 Excel 的页面设置一致。

### 打印预览

- **直接拖页边距**：预览页四边提供可拖动热区，边距不合适不必退出预览再改设置；拖动时显示正文边界、四角标记与边距数值。
- **拖动不重排**：拖动期间只移动参考线，松手才按新边距重新分页；整次拖动合并为一条撤销记录。
- **缩放三档**：整页可见（默认）/ 适应页宽（放大到页宽、允许纵向滚动）/ 实际大小。
- **版面加大**：预览弹窗宽度放宽到 `min(1240px, 96vw)`，预览区随窗口高度扩展，小窗口下也能看清版式细节。

### 工作表编辑

- **公式引用高亮**：编辑公式时高亮光标所在引用区域，`=SUM(B4:B11)` 直接框出求和范围；函数名与字符串内容不会被误判为引用。
- **fx 函数清单**：fx 入口展开常用函数清单，选中具体函数后才写入公式栏，不再直接塞一个 `SUM`。
- **合并按钮拆分**：拆成「合并居中」+ 下拉（合并单元格 / 取消合并），图标与文字同时可见，避免只靠图标猜含义。
- **颜色记忆**：颜色入口记住上次选过的颜色，主按钮一键套用，调色板改由右侧箭头展开，与 Excel 行为一致。

### Word

- **对齐快捷键**：补齐 Ctrl/Cmd + E 居中、L 左对齐、R 右对齐、J 两端对齐。

### 文件关联

- **只读格式进「打开方式」**：PDF / Markdown / HTML 登记系统关联，与 OOXML 走同一套命令行打开与冷启动路径。
- **同族扩展名补齐**：`.docm` / `.dotx`、`.xlsm` / `.xltx`、`.pptm` / `.potx`、`.markdown`、`.htm` 一并登记；缺了同族写法时右键「打开方式」会缺项。
- **不抢默认浏览器**：HTML 只登记「打开方式」，不参与「设为默认应用」申请。
- **文案与实现同源**：「设为默认应用」面板条目与扩展名提示文案改由同一份类型清单生成，不再出现面板与提示不一致。

## 修复

- **边框叠画变粗**：相邻单元格共用一条边框线时只画一次，按粗细保留更粗一侧；此前点「所有框线」后内部线比外框粗一倍。
- **冻结区表头错位**：冻结列的表头固定在左侧、冻结行的行号固定在顶部，不再随滚动移出或留下空白条。
- **冻结窗格选中框缺失**：选区按窗格范围裁剪，冻结区域同样画出选中框。
- **缩放下的坐标偏移**：CSS zoom 下 `getBoundingClientRect` 与 `offsetWidth` 不一致，先换算回网格逻辑像素再定位。
- **对话框文字截断**：类型增至 6 项后压缩行高并保持单列，窄弹窗内不再截断。

## 优化

- **中文字体优先本机同名**：本机装了同名中文字体（如方正小标宋简体）时优先使用，只有缺字才走回退栈。
- **只读格式图标**：PDF / Markdown / HTML 沿用各自品牌色，不再落进灰色占位样式。
- **快速拖选**：改用全局指针坐标替代逐单元格 `mouseenter`，快速拖动、跨冻结窗格与缩放时都能连续选中。

## 已知限制

- **打印标题未持久化**：顶端标题行目前只在当前会话内生效，尚未写回 OOXML 的 `_xlnm.Print_Titles` 定义名称，重新打开文件后需要重新设置。
- **Windows 待实机验收**：顶栏合并、自绘窗口按钮与打印分页需在 Windows 实机复核。
- macOS 仍为临时（ad-hoc）签名，未做 Apple 公证；Windows 安装包未做代码签名。
- 仅提供版本检查与提示，自动下载安装更新未做。
