# GenOffice 兼容能力接入与本轮验收

- 功能：记录 DOC 导入、原始 XML 保存和排版规则的实际落地范围；时间：2026-11-03；作者：lq。
- 当前分支：`main`，基于 `21904ce`；修改仅在工作区，未提交、推送或发布。
- 上游固定版本：GenOffice `e1f50e90d246f3ecc6427d2a0af90f04f37810ec`，来源与 Apache-2.0 许可保留在 `third_party/genoffice`。

## 已落地

1. **DOC 导入**：复用上游字体表、样式、表格、图片、页眉页脚与分节解析；以独立动态模块加载。旧 DOC 在内存转换，保存仍另存为 DOCX；XLS/PPT 沿用现有通道。转换损失以兼容警告展示，不静默切回文本提取。
2. **原始 XML 保存**：导入时建立源元素与模型块映射。无操作保存直接返回原字节；普通文字修改使用最小 w:t 补丁；未编辑块保留原 XML。新增/删除段落仍保留未触及块和未知顶层元素；原样式部件不会因普通文字修改被重写。
3. **排版规则**：停止导入时强制缩小 tblGrid；表格边框和默认单元格边距沿样式 basedOn 链继承，不再依靠英文 Grid 名称猜测。直接格式逐边覆盖、显式 nil 有效。修正网格多格行高、低倍数下限、最小值零、行距模式覆盖、snapToGrid 继承、charSpace 单位、分页段后距及新增属性的 XML 输出顺序。
4. **保存保护**：内部刷新保留已有 dirty 状态；Rust 旧格式临时路径仅取纯文件名，避免绝对参数写入原路径。静态续页阻断 contentEditable 继承，防止出现无法保存的界面修改。

## 三份真实样本

源文件只读读取自用户下载目录；以 SHA-256 验证执行前后原件不变，用户文件未复制到仓库。

| 样本 | 新转换/解析结果 | Chrome 本地应用显示页数 | 无操作保存 |
|---|---|---:|---|
| 采购文件.doc | 14 张表、2 个节、2780 个正文 rFonts 节点 | 51 | 转换后的 DOCX 字节完全相同 |
| 测试分包合同.doc | 2 个节、119 个正文 rFonts 节点 | 4 | 转换后的 DOCX 字节完全相同 |

实际浏览器检查通过应用“打开文件”界面操作，确认转换器不是只在 Node 环境可用；三个文件未捕获到 pageerror。检查了首页截图与页数，未逐页完成与 Word/WPS 的像素对比。

采购文件的明确限制：PAGEREF 和 TOC 域暂以缓存文字导入；一个无尺寸浮动对象被省略。这些限制已传递到兼容提示。分包合同的转换器未返回警告，但不代表已经证明与 Word 版面完全一致。

- Rust：`cargo test -p office-compat -p office-font`，9 项通过。
- 类型检查与 Vite 生产构建通过；原有 React act 与 Vite 动态导入提示仍存在。
- DOC 主转换模块约 183 kB（gzip 约 65 kB），独立按需加载；另有 XML/CFB 等支持代码。这里是前端构建产物大小，不是桌面安装包增量。

## 边界

- 无操作保存保证针对当前编辑模型没有变化、且提供其原始包的常规保存；不将 DOC 二进制转换称为无损。
- 文字局部补丁保留 run 属性；其他修改可能重建被修改的块。修改页设置、节、页眉页脚、批量合并，以及当前尚未建立映射的 TOC 文档，保留原有生成流程；这些路径尚不具备完整的未知节点保留保证。
- 当前自研编辑器仍使用已有的分页展示机制。静态续页禁止直接编辑；完整的连续编辑、跨页选区和输入法映射需要单独升级编辑底座，未伪装为已完成。
- 本轮没有接入 GenOffice 全部字体校准数据、完整 ProseMirror 编辑器或完整 Word 分页内核。
- 未验证 Tauri WebKit/WebView2 实机、未使用 Microsoft Word/WPS 对所有页面完成往返对照，未重新打包桌面应用。
