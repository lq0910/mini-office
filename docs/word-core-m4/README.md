# Word 新核心 M4 与默认包

功能：记录工作区与桌面平台融合、默认切换及实际本机交付证据；时间：2026-11-11；作者：lq。

M4 已完成，**0.1.10 正式默认使用 `WordCoreSession`**。新建、打开（含旧 DOC 转换后的 DOCX）、恢复、非活动标签保存、另存为和输出都使用各自的新核心会话。仅开发构建可设置 `VITE_WORD_LEGACY=true` 回退；发布构建忽略该变量，不静默改用旧序列化器。Excel/PPT 继续使用原有处理器。

## 工作区和平台实现

| 范围 | 实际行为及证据 |
| --- | --- |
| 唯一正文 | `CoreWordDocument` 仅保留引擎标识；正文、区域、选区和历史由独立会话持有，工作区订阅修订号和 dirty 摘要 |
| 版本保存 | 捕获保存版本、生成字节、平台原子写盘、确认版本分开；失败/取消不确认，保存期间的新输入保持 dirty；不通过旧 handler.serialize 保存 |
| 快照/恢复 | 自动快照保存 DOCX 字节、不确认保存版本；任务串行并补存新版本；恢复重新打开完整核心，未保存快照要求另存副本。现有 Web/Tauri 快照保留 IndexedDB 实现 |
| 另存为 | 下载或新磁盘路径后不复用原文件句柄，防止下一次保存写回旧文件 |
| 标签关闭 | 先等待已发起快照，再重新检查 dirty/保存状态；多文档退出以新核心修订号识别再次编辑；关闭才销毁会话，最后一个会话释放共享解析 worker 和内嵌字体 |
| UI 清理 | 宿主记录监听 DOM；核心先销毁、React 后卸载时不访问失效 view；关闭期间迟到的分页、尺寸观察和拖动回调安全退出 |
| 纸张与页间显示 | 产品画布背景映射到核心 `--canvas`，28px 页间带恢复可见；去掉纸面外沿和接缝阴影。提取时保留 `page-sheet/page-sheets`，混合宽度纸张在隔离层中正确绘制 |
| 字体 | Tauri 按系统字体索引、中英文别名和 TTC/OTC 字面索引读取真实 hhea/OS/2 度量，分页预取该结果；内嵌字体、替代字体和浏览器实际测量仍使用同源规则 |
| 图片/剪贴板 | 图片选择/粘贴保留核心解码与来源保存；macOS 新增 PNG + 携带尺寸/环绕信息的 HTML 原生剪贴板。剪切仅在写入成功后删除；Web/其他平台保留浏览器剪贴板能力 |
| 文件入口 | 冷启动/系统打开队列、Tauri 拖入、Web 文件拖入、手动打开都进入同一延迟注册处理器；原生允许无宏模板的 dotx 扩展保存，宏/保护限制由能力层执行 |
| 命令/输出 | 菜单与命令面板恢复打印/PDF/查找/样式/标尺入口。WebKit 的 `ProseMirror-separator` 是无 src 的光标占位图，输出不解码或克隆该编辑节点；真实媒体仍须成功解码 |

截图反馈的两项问题已修正：验收脚本不再把 `@tiptap/pm/history` 目录当成文件导入；核心销毁后的 UI 清理不再抛出 “editor view is not available”。调试脚本通过显式环境变量加载，相关 Rust 报告桥与目录隔离代码均受 `debug_assertions` 保护，不存在于发布二进制。

## 安装包与复现

版本：0.1.10；架构：macOS arm64（Apple Silicon）；`.app` 27.60 MiB；临时签名（ad-hoc）。产物位于 `output/releases/0.1.10/`：

- `Mini-Office_0.1.10_macos-arm64.dmg`
- `Mini-Office_0.1.10_macos-arm64.zip`
- `SHA256SUMS-macos-arm64.txt`

签名深度校验、DMG 镜像校验和 SHA256 清单校验通过。最终修复版 DMG 只读挂载后，镜像内应用签名校验通过，主程序与最终签名应用逐字节一致；已从镜像启动并打开公共样本，进程持续运行且启动输出无错误，该检查不代替安装后的人工编辑验收。Tauri 自带 DMG 的 Finder AppleScript 在本机超时，使用标准压缩镜像包装同一已签名应用，包含拖向 Applications 的链接。完整可复现脚本：

```bash
# 功能：构建当前默认核心并生成本机安装产物；时间：2026-11-11；作者：lq。
bash scripts/package-macos-local.sh
```

本机 WebView 验收：先在 1432 端口运行 Vite，再以调试构建的 `MINI_OFFICE_WORD_SMOKE_SCRIPT` 加载包装脚本，该包装脚本动态导入 `scripts/verify-word-core-native.mjs`；`MINI_OFFICE_WORD_SMOKE_DIR` 指定报告目录，`MINI_OFFICE_WORD_SMOKE_DATA` 指定隔离的原生数据目录。启动参数指向该报告目录下公共样本副本 `原生 验收.docx`。普通启动不执行此脚本。
