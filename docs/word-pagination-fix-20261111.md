# Word 分页与分割区修复

功能：记录用户反馈的真实样本复现、修复及验证范围；时间：2026-11-11；作者：lq。

旧 DOC 转换后的长表格在第 27 页出现切点落在表格末尾边框/留白区的情况。该位置没有后续文字行，原来的宿主直接抛出“缺少真实行锚点”，整轮页间装饰事务未提交，因此状态栏回退为 1 页，正文呈现为连续长页。

`core-page-anchor.ts` 保留真实行锚点优先级；确认切点位于最后字形之后时，改用当前正文块末的真实事务位置承接页缝，并补偿已经消耗的块尾高度。WebKit 半边框及字形取整产生不足 2 CSS px 的末行溢出也采用块末承接，完整字形保留在页缝之前。仍有明显字形穿过切点、没有可测量行或切点超出块范围时继续报错，不静默伪造锚点。每轮自然流测量共用行框缓存，避免反复遍历同一长表格。

表格页缝的 `page-gap-table-fill` 增加独立绘制层，覆盖 WebKit 折叠边框和纵向合并格绘制中穿过页缝的边框，背景继续使用产品画布色。正文、真实表格边框与保存模型保持由原会话管理。

- 用户原始合同 DOCX 在两种引擎中均为 17 页；原生截图检查第 12 页附近的合并表格页缝，边框不再穿过分割区。

## 2026-11-11 截图排版与立即滚动反馈修复

功能：对应用户五张截图、稍大文件立即滚动卡死、目录单击与 Ctrl+滚轮反馈；时间：2026-11-11；作者：lq。

本节覆盖后续修复，前文 58/59/17 页及 21:19 安装包属于历史状态。此次分别只读打开截图原合同 `【2025.9.2】…docx`、此前的 `_副本.docx` 和 `采购文件.doc`，不把两份合同当作同一个来源文件。

### 原因与实现

1. 页脚测量探针位于隔离样式之外，浮动页码框被误测为 192px 普通流块；继承文档作用域后实际正文预留约 16px。按 GenOffice 的页脚下沿距纸底定位，正文预留高度不再作为页脚条带高度重复扣减。
2. 页缝全宽 td 与纵向合并格同时参与 HTML 网格，四列表格被额外撑出列；页缝现在只填空列段，重复表头按原列边界绘制。自然测量隐藏装饰行并恢复来源 rowspan，显示时再桥接，不修改正文事务。
3. 跨页合并格中的长文字按完整行放入实际正文片段，避免居中或顶对齐长文字被页缝遮住；文字显示位移不写入保存模型。
4. WKWebView 的逐个页脚/边距按钮插入曾占用数秒；改为离线构建和批量挂载。邮件配置读取完成后保持正文宿主身份，避免整篇卸载再挂载。统计按不可变正文缓存，样式预览按样式目录缓存；滚动当前页读取合并到帧，字符测量对所有文档采用约 8ms 帧预算。
5. 首页模板不再向新核心写入旧 DocModel，直接用用户选定的公开 `tests/fixtures/docx/contract.docx` 原字节建立未保存副本。不会绑定或覆盖原模板路径。
6. 目录普通单击直接导航，保留 Ctrl/Command 单击兼容及拖选保护。导入目录优先使用原隐藏书签；旧 DOC 转换后丢失书签/样式时，匹配独立标题，列表章节号缺失仅接受唯一短标题，不依赖旧缓存页码。Ctrl+滚轮缩放正文 40%–250%，同步状态栏，普通滚轮仍翻页。
