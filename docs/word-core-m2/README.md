# Word 定制内核 M2 纵向贯通验收

功能：记录 GenOffice 衍生内核在 Mini Office 产品中的打开、编辑、分页及保存闭环；时间：2026-11-09；作者：lq。

**M2 已完成开发入口接线与本阶段验收。** 新建、打开、中文正文/普通表格编辑、跨页选区、粘贴、撤销重做、分页、保存及重开使用同一个 `WordCoreSession`。本阶段允许开发配置固定新旧引擎；默认切换仍由 M5 决定。

## 内核来源与产品边界

- 基于固定 GenOffice 提交 `e1f50e90d246f3ecc6427d2a0af90f04f37810ec` 进行源码融合和定制维护，未重写另一套简化 Word 模型。解析、模型、编辑 schema、事务、布局、原包与来源锚点、保存计划均来自这一技术链路。
- M2 追加同一来源的 `editor/note-dom.ts`、`hf-heights.ts`、`hf-phantom.ts`；来源映射从 M1 的 326 项扩展到 329 项。提取脚本逐项核验原始与本地哈希，并保留作者、日期及许可。构建不访问审计副本。
- 保留 Mini Office 的 React 18、外壳、文件标签、工具栏样式和平台文件接口；没有导入上游 App、Ribbon、Electron 或 React 19。
- `VITE_WORD_CORE_M2=true` 可在开发或试用包构建时显式启用，格式注册时固定引擎。每个文档以自己的会话确定编辑器，运行中不切引擎，不静默回退旧模型保存器。正常启动和正式发布构建仍保留原默认实现。

## 实际交付

| 内容 | 实现 |
| --- | --- |
| 开发格式入口 | `apps/desktop/src/format-handlers.ts` 按需加载 `core-handler.ts`，新建异步生成完整 DOCX 包，打开直接创建完整核心会话 |
| 产品页面 | AppShell 挂载 `WordCoreEditor.tsx`，复用现有 WordToolbar；加粗、斜体、下划线、删除线、撤销重做及保存直接操作当前核心 |
| 单一权威状态 | 工作区 `data` 只保留 `{ engine: 'word-core' }` 标识，`wordCore` 持有完整模型、原始包、编辑器和修订号；不生成旧 DocModel 正文 |
| 正文宿主 | `WordCoreSurface.attach()` 可重复挂载工作区会话；隐藏或 React 卸载只清理宿主，关闭文档才销毁核心，保留正文、选区和撤销历史 |
| 分页 | `core-layout.ts` 和 `core-layout-context.ts` 连接同源 BlockPlan、自然流测量、分节/栏/竖排装饰、行盒切片、重复表头、行高补偿、浮动对象及原始 XML 来源定位 |
| 页面附属区域 | 同源页眉页脚变体和高度探测，页码、脚注预留与页底区域、尾注参与切片；多纸张显示、边框及嵌套表格切点覆盖层 |
| 输入与显示调度 | 组合输入期间不重排；组合结束、事务、字体/图片加载、宽度或缩放变化触发重排；宽度和行高的后续测量有界收敛 |
| 写盘闭环 | 捕获核心版本 → 生成不可变字节 → 平台接口写盘 → 确认该版本；失败/取消不确认，并发写盘被拒绝，保存期间继续编辑保持 dirty |
| 必要工作区接线 | 非活动会话也能保存；恢复快照以 DOCX 字节重新打开新核心；快照生成不确认保存；手动保存等待已启动的快照序列化 |
| 原路径隔离 | 新核心会话拒绝旧 `updateData` / `updateDocMeta` 写入，旧模型宏不可执行；旧序列化入口收到新核心标识会明确失败，不伪造保存成功 |

M4 的部分生命周期工作是 M2 产品纵向链路的必要前置，已在本轮接通；这不等于 M4 的所有平台及异常场景都已验收完成。

## 保存及布局中的本地修正

1. 页间装饰不进入正文或撤销历史；测量及锚点解析在自然流中进行，异常后恢复测量状态，避免上一轮装饰把下一轮换行锁死。
2. 消除末行 leading 溢出导致的逐页物理边界偏移；按同源纸张边缘补足末页，并处理多栏末页仍以堆叠方式存在的不可见尾部空间。
3. 保存后的 dirty 根据核心修订号确认，不再依赖 `session.data` 对象是否变化。平台只接收快照字节副本。
4. 恢复后立即保存会等待后台快照完成，避免同一核心序列化竞争。慢快照进行中又有新请求时，旧任务结束后补存最新版本；排队期间的新编辑优先于旧请求的 clean 标记。
5. 原生文档保护在事务层只读，不能通过开发入口或直接命令绕过。解析期间关闭的标签不会被迟到结果复活。

## 复现


```bash
# 功能：验证源码、构建、真实分页及真实产品页面；时间：2026-11-09；作者：lq。
pnpm verify
node scripts/verify-word-core-surface.mjs
node scripts/verify-word-core-workspace.mjs
```
